# 备忘：挂账与功能 Backlog

> 本文件是「还没做的事」的单一事实源（2026-09-06 起）。
> **挂账** = 已知债务，多带触发条件；**Backlog** = 尚未开发的功能，按建议优先级分组。
> 完成一项就勾记并注明出处；新想法先记到这里，评审后转正为某期计划（`Docs/plans/`）。

## 一、挂账（债务 / 条件触发）

| 项 | 触发条件 | 备注 |
|---|---|---|
| AI 在玩家无敌帧期间仍发起攻击（空挥） | AI 行为完善时 | 追击逻辑补目标无敌判断即可 |
| 受击盒收贴美术剪影（玩家侧宁小勿大） | 正式美术接入 | 需同步重标定 `_attackDistance`（命中可达 = 偏移 + 命中盒半宽 + 目标受击盒半宽） |
| 房间几何迁移 TileMapLayer | 美术素材到位 | 绘制成本远低于手摆 StaticBody+ColorRect；碰撞随 TileSet 物理层自动生成；流式/相机/探针不受影响 |
| 敌人房间休眠策略 | 世界规模扩大后 | 当前 3×3 窗口内全模拟，测试世界无压力 |
| 关卡异步加载（`LoadThreaded`） | 单房间体量增大后 | 当前同步实例化足够 |
| 脚本目录可选整理 | 顺手时 | ① ScreenShake/CameraRig/Presenter 挪 `Presentation/`（纯外观收益）；② 配置四件套挪 `Config/`（需连带改 `.tres` 脚本路径）——均已评估为低收益暂缓 |

## 二、功能 Backlog

### P0 —— 没有就不算完整游戏

- [ ] **音频系统**：BGM（菜单/游玩）+ 音效（跳/落地/挥击/命中/受击/死亡/重生/UI/接触）。
  架构已预留：逻辑层事件齐全（`Jumped`/`Landed`/`AttackStarted`/`HitConfirmed`/`Damaged`/`Died`），
  挂一个音频编排节点订阅即可，逻辑层零改动
- [ ] **死亡反馈**：当前静默重生——至少死亡暗角/文字提示 + 音效，让「死了」可感知
- [ ] **出口可视化与目标感**：门占位美术 + 靠近提示（如「↑ 进入」），让「通关去哪」可读
- [ ] **正式关卡内容**：3–5 房间的有设计世界（教学 → 战斗 → 捷径/秘密房），复用房间规范
  （边界对齐、Spawn 标记、背景 z_index=-10——见 architecture.md §11）

### P1 —— 玩法深度

- [ ] **第二种敌人**（远程或飞行）：验证「新增敌人 ≈ 输入源+配置+外观」的扩展承诺
- [ ] **敌人死亡反馈**：死亡特效/粒子/小动画（当前直接消失）
- [ ] **手感打磨包**：hitstop 顿帧、受击闪白、攻击段间位移微调
- [ ] **拾取物**：回血（Health 补 `Heal` API + 事件）、计数收集物
- [ ] **检查点/存档**：房间存档点道具（复活点语义已就绪：`SetSpawnPoint`）
- [ ] **AI 完善**：无敌期不攻击（挂账转正）、巡逻/追击参数外置调优

### P2 —— 完成度

- [ ] 手柄支持与按键重映射（InputMap 已集中，成本低）
- [ ] 设置菜单（音量/全屏/震屏开关——ScreenShake.Enabled 已有开关先例）
- [ ] 小地图/世界地图（房间网格数据现成）
- [ ] Game Over 结算页（若引入生命次数机制）
- [ ] 本地化框架（`tr()` 埋点越早越省）
- [ ] 性能预算基线（profiler 跑一次，记录房间数-帧率曲线）
